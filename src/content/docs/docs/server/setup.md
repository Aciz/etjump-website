## Requirements

- A working Enemy Territory dedicated server
- The ETJump server package
- Write access to the server's `etmain` and mod directories

## Start the server

```sh
./etlded +set fs_game etjump +exec server.cfg +map oasis
```

## Configuration

Server settings live in `server.cfg`. ETJump-specific cvars use the `g_` prefix and are documented on the server cvars
page once it is migrated.
