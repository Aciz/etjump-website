ETJump is a trickjump modification for Wolfenstein: Enemy Territory. You need a working Enemy Territory installation
before installing the mod.

## Install

1. Download the latest ETJump release.
2. Extract the package into your Enemy Territory installation directory.
3. Start the game and connect to an ETJump server.
