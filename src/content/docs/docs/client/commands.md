---
title: Commands
description: Console commands available in ETJump.
---

Commands are entered in the console. Many of them have client-side aliases that can be bound to keys.

| Command           | Description                                     |
| ----------------- | ----------------------------------------------- |
| `timerun`         | Prints timerun information for the current map. |
| `records`         | Prints timerun records.                         |
| `loadcheckpoints` | Loads checkpoints for comparison during a run.  |
| `savepos`         | Saves your position, angles and velocity.       |
| `loadpos`         | Restores a saved position.                      |
| `noclip`          | Toggles noclip (server permission required).    |
